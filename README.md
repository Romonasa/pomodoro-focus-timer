🍅 Pomodoro-Focus-Timer

Eine kostenlose Uhr, die dir hilft, konzentriert zu arbeiten — mit einem eingebauten Meeting-Wecker und von Grund auf für Barrierefreiheit gebaut. Keine Installation, kein Konto, keine Kosten.

[→ Uhr jetzt öffnen](https://romonasa.github.io/pomodoro-focus-timer/Pomodoro-Focus-Timer.html)

Was ist das?

Die Pomodoro-Technik teilt Arbeitszeit in kurze, konzentrierte Abschnitte mit Pausen dazwischen ein — bewährt gegen Aufschieberitis und für nachhaltige Konzentration, statt stundenlang ohne Unterbrechung durchzuarbeiten.

Dieser Timer setzt das um, mit zwei Dingen, die im Alltag oft fehlen:

Meeting-Modus — kein Pomodoro-Zyklus, sondern ein dezenter persönlicher Wecker für Besprechungen mit fester Dauer, inklusive Vorwarnung ein paar Minuten vor Schluss, für einen pünktlichen statt gehetzten Abschluss
Barrierefreiheit als Kernfeature — hoher Kontrast, blinkfreie Alarmierung, vollständige Tastaturbedienung, Screenreader-Ansagen — nicht nachträglich angeflanscht, sondern von Anfang an mitgedacht
So nutzt du die Uhr
Für alle Geräte (empfohlen)

Einfach den Link oben öffnen. Funktioniert auf Windows, Mac, Linux, iPhone/iPad und Android, in jedem Browser — ganz ohne Download oder Installation. Einzige Voraussetzung: eine Internetverbindung beim ersten Öffnen.

Tipp fürs Handy: Über das Browser-Menü "Zum Startbildschirm hinzufügen" wählen — dann hast du ein Icon wie bei einer echten App.

Ohne Internet nutzbar

Falls du die Uhr an einem Ort ohne Internetzugang brauchst (z. B. Schule ohne WLAN):

Pomodoro-Focus-Timer.html herunterladen (Datei anklicken → Download-Symbol)
Irgendwo speichern (z. B. im Ordner "Downloads")
Von dort per Doppelklick öffnen — läuft danach komplett offline

⚠️ Diese heruntergeladene Datei und der Online-Link oben teilen sich keine Einstellungen — sie laufen technisch getrennt voneinander.

Eigenes App-Fenster für Windows (optional)

Pomodoro-Focus-Timer-starten.bat herunterladen und öffnen — zeigt die Uhr in einem eigenen, schlanken Fenster ohne Tabs und Adressleiste. Braucht Chrome oder Edge sowie eine Internetverbindung beim Start.
